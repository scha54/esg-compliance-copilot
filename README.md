# ESG Compliance Copilot

Controlled compliance copilot for GHG accounting and CSRD/SEC climate disclosure — ingests activity data, classifies GHG scope, matches emission factors, drives all arithmetic through a deterministic calculation tool, validates data quality, reviews sustainability claims for greenwashing risk, compiles gated disclosure dossiers, and traces full audit lineage for every figure.

This is a **git-native agent** in [GitAgentProtocol (GAP)](https://www.gitagent.sh) format:
the agent's entire identity lives in this repository as plain files — versioned,
reviewable, and forkable like any codebase. It was created with
[Architect](https://architect.new), which keeps this repository in sync with the
app it belongs to (edits made here are merged back automatically).

## Skills

- **ingest-normalize-activity-data** — Normalizes ERP/invoice/freight/travel uploads (CSV/XLSX/PDF) into activity_records rows, dedupes, stamps lineage, masks sensitive values, flags missing required fields, and never fabricates a row.
- **classify-ghg-scope** — Assigns Scope 1/2/3(+category)/Excluded/human-review to activity records with rationale, evidence, and confidence, testing ownership/control first and never forcing a low-confidence classification.
- **match-emission-factor** — Binds classified activity records to an approved emission factor from the seeded library via strict priority hierarchy, labelling every compromise and never inventing a factor.
- **deterministic-emissions-calc** — Converts an activity record and bound factor into a traceable tCO2e figure by calling the deterministic calc TOOL only — never computes the arithmetic itself.
- **validate-data-quality** — Scans normalized/classified/calculated records for duplicates, negative quantities, statistical spikes, and currency/period mismatches, raising ANOMALY_REQUIRES_REVIEW exceptions rather than silently correcting or discarding.
- **greenwashing-claim-review** — Tests sustainability claims against calculated emissions data and evidence, registering unsupported or contradicted claims as guarded risk findings — never asserting a legal conclusion.
- **compile-disclosure-dossier** — Runs the five mandatory gates (Calculation Integrity, Factor Integrity, Completeness, Greenwashing, Auditability) against current data for the selected entity/period/jurisdiction, emitting a READY dossier or an exact BLOCKED_PENDING_REVIEW list — never generating a dossier while a gate fails.
- **trace-audit-lineage** — Given any disclosure figure, calculation ID, or activity record, walks the full chain backward and forward, producing an addressable, exportable lineage chain with nothing produced by unlogged model arithmetic.

## Editing this agent

Edit the files above directly (here on GitHub or via a clone) and the changes
merge back into the live app on its next sync. `memory/MEMORY.md` uses git's
union merge, so memory written by the running agent never conflicts with your
edits.

## Running standalone

The repo is portable — it runs anywhere with the open-source
[`@open-gitagent/gitagent`](https://www.npmjs.com/package/@open-gitagent/gitagent) runtime:

```bash
export ANTHROPIC_API_KEY=sk-...   # anthropic:claude-sonnet-4-6
npx @open-gitagent/gitagent --dir . "Hello!"
```

Inside its Architect app it runs through the owner's Lyzr account instead — no
separate model key needed there.
